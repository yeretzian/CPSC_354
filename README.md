## Assignment 1: Calculator with Lark

The `Assignment1` folder has a calculator written in Python that uses a parser generated by Lark.

- `grammar.lark` is the context-free grammar
- `calculator_cfg.py` is the calculator code
- `specs.md` explains how everything works

To run it:

```
pip install lark
cd Assignment1
python calculator_cfg.py "1+2*3"
```
